# Multiplayer 1 vs 1 via Link (WebRTC P2P)

O modo multiplayer conecta dois jogadores humanos diretamente no navegador.

## Como Jogar 1 vs 1

1. Clique em **Convidar 1v1** na barra superior.
2. Clique em **Gerar Link de Convite** e copie o endereço com `?sala=<id>`.
3. Envie o link para o segundo jogador.
4. O anfitrião joga com as Brancas e o convidado joga com as Pretas.
5. Ambos os navegadores validam cada lance com `chess.js`.
