# Skins Personalizáveis das Peças (64×64 PNG)

Esta pasta contém as skins padrão usadas no **Modo Animado (Skinview3D)**.
Os jogadores podem editar ou substituir qualquer arquivo `.png` abaixo mantendo o tamanho **64×64 pixels**:

| Arquivo | Peça |
| :--- | :--- |
| `w_k.png` / `b_k.png` | Rei (Brancas / Pretas) |
| `w_q.png` / `b_q.png` | Rainha (Brancas / Pretas) |
| `w_b.png` / `b_b.png` | Bispo (Brancas / Pretas) |
| `w_n.png` / `b_n.png` | Cavalo (Brancas / Pretas) |
| `w_r.png` / `b_r.png` | Torre (Brancas / Pretas) |
| `w_p.png` / `b_p.png` | Peão (Brancas / Pretas) |

Nos modos de daltonismo, o jogo usa paletas adaptadas automaticamente para preservar o contraste.
